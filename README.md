# Мастерская Андрея Сергеевича Горшкова

Обновлённый официальный сайт семейного психотерапевта, автора практик и мастера Андрея Сергеевича Горшкова.

Сайт объединяет подтверждённую профессиональную биографию, направления практики, авторские работы, публикации о выставках, видеоматериал и контакты мастерской.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Проверка производственной сборки:

```bash
npm test
```
