# Мастерская Андрея Сергеевича Горшкова

Публичная статическая версия современного сайта-портфолио семейного психотерапевта, автора практик и мастера Андрея Сергеевича Горшкова.

Сайт объединяет подтверждённую профессиональную биографию, направления практики, авторские работы, публикации о выставках, видеоматериал и контакты мастерской.

## Публичные версии

- [Основной сайт](https://andrey-gorshkov.semenovspb.chatgpt.site/)
- [GitHub Pages](https://daridarom.github.io/andrey-gorshkov-workshop/)

## Структура

- `index.html` — готовая статическая страница;
- `assets/` — стили, оригинальный логотип и оптимизированные фотографии.

## Материалы и источники

Фирменный логотип, фотографии Андрея Сергеевича и изображения авторских работ используются без искажения из официальных материалов мастерской. Новая подборка работ взята из материалов, опубликованных на официальном сайте в апреле 2024 года. Права на персональные и художественные материалы сохраняются за их правообладателями.
