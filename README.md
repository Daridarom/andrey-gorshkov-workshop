# Мастерская Андрея Сергеевича Горшкова

Основной сайт: https://andrewgorshkov.ru/

Демонстрационная копия: https://daridarom.github.io/andrey-gorshkov-workshop/

В этом репозитории хранится готовая опубликованная страница. Канонический адрес обеих копий — основной домен. Изменения исходников собираются в один комплект для GitHub и Beget; изменение GitHub не переключает Beget автоматически.

Обновление от 9 сентября 2026 года: исправлена адаптация видеофона, упрощены консультации и навигация, добавлены прямые переходы к коллекциям, отдельные счётчики фотографий, названия фильмов VK и обложка для социальных сетей. Подписи к изображениям изменены по просьбе владельца. Адреса ресурсов содержат версию для корректного обновления кеша.

Редактируемые исходники и инструкция обновления сохранены владельцу отдельным архивом. На публичный хостинг загружаются только готовые файлы.

Порядок хранения версий по указанию владельца от 9 сентября 2026 года: новые резервные копии страниц на Beget не создавать. Сохранённую первую версию сайта оставлять без изменений. Все последующие версии и историю изменений хранить в GitHub.

## Исправления мобильной версии и превью

Дополнительные исправления от 9 сентября 2026 года находятся в `assets/responsive.css` и подключены после основного оформления. На телефонах и планшетах шапка прокручивается вместе со страницей. В блоке о лабиринтах отменено ошибочное размещение обеих колонок в одной строке. Исправлены переносы длинных слов, сетки, подписи, меню и отступы, в том числе при увеличении текста до 200%.

Проверены размеры окна 320, 375, 430, 640, 768, 928, 1024 и 1280 пикселей в Chromium; отдельно проверен узкий экран с увеличенным текстом. Проверка в браузере на физическом iPhone остаётся полезной для особенностей Safari и встроенных браузеров приложений.

Обложка `og.jpg` — JPEG RGB 1200 × 628, 125 077 байт. В начальном HTML заданы Open Graph и Twitter Card, HTTPS-адрес, формат, размеры и описание изображения. Обложка сохранена без изменений. Наличие метаданных не гарантирует обновление уже закэшированных карточек в мессенджерах; фактическая загрузка роботом Telegram здесь не проверялась.

9 сентября 2026 года исправления опубликованы в основной ветке GitHub, на GitHub Pages и на Beget: сначала загружен `assets/responsive.css`, затем заменён `index.html` в существующей публичной папке. На основном домене подтверждены загрузка нового CSS, обновлённые метаданные и доступность обложки 1200 × 628. Новые резервные копии на Beget не создавались. Изменение GitHub само по себе не обновляет основной домен.

## Локальный просмотр

Для разработки используется Vite. Установите зависимости через `npm ci`, затем выполните `npm run dev`. Сборка для публикации не требуется: сайт остаётся обычной статической страницей. `package.json`, lockfile, конфигурация Vite и служебные каталоги не нужны на Beget.
