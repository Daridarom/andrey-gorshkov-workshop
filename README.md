# Мастерская Андрея Сергеевича Горшкова

Основной сайт: https://andrewgorshkov.ru/

Демонстрационная копия: https://daridarom.github.io/andrey-gorshkov-workshop/

В этом репозитории хранится готовая опубликованная страница. Канонический адрес обеих копий — основной домен. Изменения исходников собираются в один комплект для GitHub и Beget; изменение GitHub не переключает Beget автоматически.

Обновление от 9 сентября 2026 года: исправлена адаптация видеофона, упрощены консультации и навигация, добавлены прямые переходы к коллекциям, отдельные счётчики фотографий, названия фильмов VK и обложка для социальных сетей. Подписи к изображениям изменены по просьбе владельца. Адреса ресурсов содержат версию для корректного обновления кеша.

Редактируемые исходники и инструкция обновления сохранены владельцу отдельным архивом. На публичный хостинг загружаются только готовые файлы; резервные копии и служебные данные хранятся вне публичной папки.
